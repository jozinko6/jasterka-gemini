# UI Guidelines - Jašterka Hlohovec

## Aesthetic: Premium Gastro
- **Colors:**
  - `bg-olive-900`: #1b2610 (Dark green)
  - `bg-olive-700`: #3a4d2c (Olive)
  - `bg-cream-100`: #fdfaf5 (Light background)
  - `bg-orange-500`: #f97316 (CTA)
- **Typography:**
  - Headings: Serif (Georgia or Modern Playfair)
  - Body: Sans-serif (Inter/Helvetica)

## Layout Patterns
- Minimalist navigation.
- Large cards for food items.
- Elegant transitions using Framer Motion.
