# Project Brief - Jašterka Hlohovec

## Cieľ
Vytvoriť komplexný gastro ekosystém pre Reštauráciu Jašterka v Hlohovci, zahŕňajúci web, objednávky, kuchynský workflow a vlastný delivery systém.

## Hlavné moduly
- **Public Website:** Prezentácia, menu, rezervácie.
- **Ordering System:** Košík, checkout (pickup/delivery), tracking.
- **Kitchen System:** Dashboard pre kuchyňu, stavy objednávok.
- **Delivery System:** Správa kuriérov, zóny, dispatch, optimalizácia trás.
- **Admin System:** Správa menu, objednávok, štatistiky.

## Cieľová skupina
Zákazníci reštaurácie Jašterka, personál kuchyne, kuriéri a manažment.
